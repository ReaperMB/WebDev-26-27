Web Technologies

HTML

HTML (Hyper Text Mark Language) Pure Text date that is "marked up". It is the structure of a web page and allows the browser to render what is inside of the web page. It Is NOT a prgramming language.

CSS

CSS (Cascading Style Sheets) used to design, style, and control the visual presentation of web pages.

JavaScript

JavaScript is a High-level programming language that serves one of the core technologies of the World Wide Web. JavaScript is a dynamic programming language used to make web pages interactive and alive. It works alongside HTML and CSS to add features like animations, pop-up menus, and real-time content updates.

jQeury

jQeury is a fast, small, and lightweight JavaScript library designed to simplify how developers interact with HTML documents.

Bootstrap

A Massive collection of pre-written HTML,CSS, and Javascript code used to build responsive websites quickly.

A-Frame

A-Frame is an open-source web framework used to create 3D, augmented reality (AR),and virtual reality (VR) experiences using basic HTML.

TypeScript

TypeScript is a stricter, "smarter" version of JavaScript. It adds type saftey to prevent errors in massive web applications, making it incredilby popular for enterprise web development.

C#

C# Developed by Microsoft, this language is heavily ultilized for buiding Windows desktop applications and is the primary language for game development using the Unity game engine.
